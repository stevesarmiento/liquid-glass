# Security Policy

## Supported Versions

Liquid Glass is pre-1.0. Security fixes target the latest code on `main` and the latest published package version when one exists.

## Reporting A Vulnerability

Please do not open a public issue with exploit details.

Use GitHub private vulnerability reporting for this repository if it is available. If private reporting is not available, open a public issue requesting a private security contact and include only a brief, non-sensitive summary.

Helpful details include:

- affected package, version, or commit
- reproduction steps
- impact
- whether the issue affects browser consumers, build tooling, WASM, or docs/demo apps
- any known mitigations

The maintainer will acknowledge valid reports, investigate impact, and coordinate a fix or disclosure timeline based on severity.
