# Support

Use GitHub issues for reproducible bugs, rendering regressions, package problems, and feature requests:

https://github.com/stevesarmiento/liquid-glass/issues

For usage questions, start with the README files and docs in this repo. If the answer is not covered, open an issue with the `question` label or use GitHub Discussions if they are enabled.

For vulnerabilities, follow [`SECURITY.md`](SECURITY.md) and avoid posting exploit details publicly.
